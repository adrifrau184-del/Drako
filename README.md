# 👑 DRAKO

Bienvenido a DRAKO, una marca de ropa streetwear premium con un estilo moderno, exclusivo y elegante.

## 🔥 Características

- Diseño blanco y negro.
- Catálogo de ropa.
- Carrito de compra.
- Compatible con móvil y ordenador.
- Desarrollado con HTML, CSS y JavaScript.
- Preparado para GitHub Pages.

## 📦 Productos

- Camisetas DRAKO
- Sudaderas DRAKO
- Pantalones DRAKO

## 🚀 Instalación

1. Clona el repositorio.
2. Abre `index.html` en tu navegador.
